# Downloads and Desktop Organizer - Tool 5

Sorts loose files into folders by type.

## Run it

Windows: double-click `run.bat`
Mac / Linux: double-click `run.sh`, or in a terminal run:
`python3 file_organizer.py`

You need Python 3. Get it from python.org if you do not have it.

## What it does

1. Pick 1 for Downloads, 2 for Desktop,
   or 3 for another folder.
2. It shows a preview of where each file will go.
3. Type `yes` to move them.
4. Files go to Images, Documents, Videos,
   Music, Archives, Code, or Others.
5. Nothing is deleted. Files still downloading
   are skipped. If a name already exists,
   it adds (1), (2), and so on.
