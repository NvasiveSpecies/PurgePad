# Disk Space Analyser - Tool 4

Shows how much drive space you have left,
and what is using it.

## Run it

Windows: double-click `run.bat`
Mac / Linux: double-click `run.sh`, or in a terminal run:
`python3 disk_space.py`

You need Python 3. Get it from python.org if you do not have it.

## What it does

1. Asks for a folder, or press Enter for your home folder.
2. Shows total, used, and free space.
3. Lists the 10 biggest folders.
4. Lists the 10 biggest files.
5. Lists space by file type.
6. Optional delete: type the numbers of big
   files to delete, then type `yes`.
   Files only, never folders. Press Enter
   to keep everything.
