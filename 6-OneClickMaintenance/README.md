# One-Click Maintenance - Tool 6

Does the safe clean-up jobs in one go.

## Run it

Windows: double-click `run.bat`
Mac / Linux: double-click `run.sh`, or in a terminal run:
`python3 one_click_maintenance.py`

You need Python 3. Get it from python.org if you do not have it.

## What it does

1. Shows free space before.
2. Finds temp and junk files, shows how many
   and how big they are.
3. Asks you to type `yes` once, then deletes
   temp files only.
4. Counts the apps that start at login.
   It does not turn any off.
5. Shows free space now.

No registry cleaner, no driver updater,
no RAM booster, no speed promises.
