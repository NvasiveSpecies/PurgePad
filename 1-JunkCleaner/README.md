# Junk Cleaner - Tool 1

Cleans temporary files on Windows, Mac, and Linux.

## Run it

Windows: double-click `run.bat`
Mac / Linux: double-click `run.sh`, or in a terminal run:
`python3 junk_cleaner.py`

You need Python 3. Get it from python.org if you do not have it.

## What it does

1. Finds files in your temporary folders.
2. Shows you how many files, and how big they are.
3. Shows the first 20 files.
4. Asks you to type `yes` before it deletes anything.
5. Deletes files only, never folders.

It never deletes anything without asking first.
